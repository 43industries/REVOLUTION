# REVOLUTION

**No Electricity. No Mercy.** — 2D stickman combat (pygame) + anime 3D remake (Godot 4).

| Build | Path | How to run |
|---|---|---|
| Reference (pygame) | `revolution.py` | `Play.bat` or `python revolution.py` |
| Remake (Godot 4) | [`RevolutionGodot/`](RevolutionGodot/) | `PlayGodot.bat` or open folder in Godot 4 |

Trailer: open `trailer.html` (or press **T** on the pygame title screen).

Shared story: [`story/campaign_story.json`](story/campaign_story.json) (briefings, clears, radio, sector env ids).
